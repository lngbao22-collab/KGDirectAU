================================================================================
  HƯỚNG DẪN CÀI ĐẶT - KGDirectAU
  (Knowledge Graph + Alignment-Uniformity)
================================================================================

Tài liệu này hướng dẫn cài đặt môi trường để chạy dự án KGDirectAU trên máy tính
cá nhân hoặc máy chủ. Đọc kỹ trước khi bắt đầu train mô hình.



1. YÊU CẦU PHẦN CỨNG

  Khuyến nghị (có GPU NVIDIA):
  - GPU: NVIDIA có hỗ trợ CUDA (GeForce RTX / Tesla / A100...)
    + SimKGC và các mô hình dùng BERT cần nhiều VRAM hơn (>= 8 GB khuyến nghị)
    + Các mô hình KGE thuần (DistMult, RotatE, TransE...) có thể chạy với 4-6 GB
  - RAM hệ thống: >= 16 GB (32 GB tốt hơn nếu train SimKGC với batch lớn)
  - Ổ cứng: >= 10 GB trống cho mã nguồn, dataset và checkpoint
    + Dataset WN18RR / FB15k-237: ~100-500 MB (tùy bản preprocessed)
    + Thư mục logs/ có thể lớn dần theo số lần train

  Tối thiểu (chỉ CPU, không khuyến nghị cho SimKGC):
  - CPU: 4 nhân trở lên
  - RAM: >= 8 GB
  - Train sẽ rất chậm; một số tính năng AMP/GPU sẽ tự tắt

  Kiểm tra GPU (nếu có):
    nvidia-smi

  Cột "CUDA Version" trong nvidia-smi giúp chọn phiên bản PyTorch phù hợp.


2. YÊU CẦU PHẦN MỀM

  Bắt buộc:
  - Hệ điều hành: Windows 10/11, Linux, hoặc macOS
  - Python: >= 3.8 (khuyến nghị 3.10 hoặc 3.11)
  - pip (đi kèm Python)

  Khuyến nghị (train trên GPU):
  - NVIDIA Driver mới nhất tương thích với GPU
  - CUDA Toolkit tương ứng (PyTorch sẽ cài bản CUDA riêng qua pip)

  Thư viện Python chính (xem requirements.txt):
  - torch              (cài RIÊNG trước, xem mục 5)
  - transformers       >= 4.15
  - tokenizers         >= 0.10.0
  - sentencepiece      >= 0.1.95
  - numpy              >= 1.19
  - tqdm               >= 4.0
  - scikit-learn       >= 0.24
  - typing-extensions  >= 3.10
  - protobuf           >= 3.19

  Thư viện phụ (chỉ cần khi chạy tìm kiếm siêu tham số scripts/hpo/):
  - optuna >= 3.0
  - pandas >= 1.3
  - matplotlib >= 3.5


3. TRUY CẬP VÀO MÃ NGUỒN DỰ ÁN

  Mở terminal / PowerShell, di chuyển đến thư mục làm việc:

    T826_KL_KHMT23/sources/Experiments/


4. TẠO MÔI TRƯỜNG ẢO (VIRTUAL ENVIRONMENT)

  Bước này giúp tách thư viện của dự án, tránh xung đột với Python hệ thống.

  --- Windows (PowerShell) ---

    python -m venv .venv
    .venv\Scripts\Activate.ps1

  Nếu bị chặn thực thi script, chạy một lần (PowerShell với quyền Admin):
    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

  --- Linux / macOS ---

    python3 -m venv .venv
    source .venv/bin/activate

  Khi thành công, đầu prompt sẽ có tiền tố (.venv).

  Thoát môi trường ảo:
    deactivate


5. CÀI ĐẶT PYTORCH

  PyTorch KHÔNG nằm trong requirements.txt. Cần cài trước theo phiên bản CUDA
  phù hợp với driver GPU.

  Kiểm tra CUDA version:
    nvidia-smi

  Ví dụ cài đặt (chọn MỘT dòng phù hợp):

    # CUDA 12.6 (ví dụ driver hiện CUDA 12.x)
    pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu126

    # CUDA 12.1
    pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

    # CPU only (không có GPU)
    pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu

  KHÔNG nên dùng "pip install torch" đơn giản — có thể tải bản CUDA quá mới,
  không tương thích với driver hiện tại.


6. CÀI ĐẶT CÁC THƯ VIỆN CÒN LẠI

  Trong môi trường ảo đã kích hoạt, tại thư mục gốc Experiements:

    pip install -r requirements.txt

  Kiểm tra PyTorch nhận GPU:
    python -c "import torch; print(torch.cuda.is_available())"

  In ra True nghĩa là GPU sẵn sàng.


7. CHUẨN BỊ DỮ LIỆU (BẮT BUỘC TRƯỚC KHI TRAIN)

  Codebase chứa 2 dataset gồm các file như sau:

  --- WN18RR (data/WN18RR/) ---
    train.txt
    valid.txt
    test.txt
    valid_w_label.txt      (triple classification)
    test_w_label.txt       (triple classification)
    wordnet-mlj12-definitions.txt

  Nguồn tham khảo: https://github.com/TimDettmers/ConvE

  --- FB15k-237 (data/FB15k237/) ---
    train.txt
    valid.txt
    test.txt
    FB15k_mid2name.txt

  Nguồn tham khảo: https://web.informatik.uni-mannheim.de/LinkedData/FB15K237/

  --- Tiền xử lý (một lần cho mỗi dataset) ---

    python data/preprocess.py --dataset wn18rr
    python data/preprocess.py --dataset fb15k237

  Kết quả ghi vào:
    data/WN18RR/preprocessed/
    data/FB15k237/preprocessed/

8. KIỂM TRA CÀI ĐẶT THÀNH CÔNG

  1. Môi trường ảo đang bật (.venv)
  2. torch.cuda.is_available() trả về True (nếu có GPU)
  3. Đã có file data/WN18RR/preprocessed/train.txt.json (hoặc tương tự FB15k237)
  4. Chạy thử lệnh help:
       python main.py --help

  Nếu tất cả bước trên ok, chuyển sang file HuongDanSuDung.txt để bắt đầu train.
